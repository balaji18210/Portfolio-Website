# Personal Portfolio Website

A responsive personal portfolio website developed as a basic Web Development Project using HTML5, CSS3, JavaScript, and Bootstrap 5.

The website is designed to showcase personal information, technical skills, services, projects, and contact details in a clean and user-friendly format.

---

##  Project Information

**Project Title:** Personal Portfolio Website

**Project Type:** Web Development Project

**Developed By:** A. Balaji

**Technologies Used:** HTML5, CSS3, JavaScript, Bootstrap 5

**Project Status:** Completed

---

##  Introduction

A personal portfolio website is a digital profile that presents information about a person, their skills, projects, services, and professional interests.

This project focuses on developing a simple, responsive, and user-friendly portfolio website. It provides an organized platform to showcase web development skills and sample projects.

The website is created using HTML5 for the structure, CSS3 for styling, JavaScript for interactive features, and Bootstrap 5 for responsive layouts and ready-made components.

---

##  Project Objectives

The main objectives of this project are:

- To create a professional personal portfolio website.
- To practice HTML5 and CSS3.
- To understand JavaScript basics and interactive features.
- To use Bootstrap for responsive web design.
- To showcase technical skills and projects.
- To create a simple and user-friendly interface.
- To understand the structure of a real-world website.
- To improve basic web development skills.

- Laptop
